# Tree

第2回講義資料によると、LoRAとQLOARの仕組みは以下のようになっています。

* **LoRA（Low-Rank Adaptation）**
  * **何を固定するか：** 元のモデルの重み（$W$）を**固定**し、学習させません（第2回・PDF p.52）。
  * **何を学習するか：** 変化分を表す小さな行列（低ランクの行列 $A$ と $B$）の「差分」だけを学習します（第2回・PDF p.52）。イメージとしては、モデル本体は動かさずに薄い「付箋」に書き足すような形で、全体のごく一部（1%未満）だけを調整します。

* **QLoRA（Quantized LoRA）**
  * **何を加えるか：** LoRAの手法に加えて、元の重みを**4bit（数値を粗く保存する量子化）に圧縮**するという仕組みを加えます（第2回・PDF p.52）。これにより、数十億パラメータ規模の大きなモデルでも、GPU 1台（Google Colabの無料〜有料枠など）で微調整（Fine-Tuning）できるようになります。
